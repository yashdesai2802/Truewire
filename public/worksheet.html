02/09/2026 Project Discussion Finalized the TrueWire project idea for checking whether news, links, images and online content are genuine or misleading. Formulated system requirements for a live newsroom verification desk. 2 hr Project problem, objectives, and scope defined.
06/09/2026 Research Researched live Indian news RSS feeds (Aaj Tak, ABP News, NDTV India, Zee News, Jagran) and multimodal AI models (Gemini, OpenAI, Claude) for corroboration against live web wire sources. 3 hr Suitable Hindi news sources and fact-checking methodology identified.
11/09/2026 Backend Architecture Set up Node.js Express server architecture, modular directory structure (routes, services, middleware, utils), environment variables (.env), and rate limiters to protect AI API quotas. 3 hr Express backend with Helmet security and CORS initialized.
16/09/2026 News Aggregator Coding Developed newsService.js for multi-feed RSS parsing across 10+ Hindi channels. Added in-memory caching (5-min TTL), headline deduplication, and preserved original Devanagari Hindi text. 3 hr 300+ live news stories fetched and cached successfully.
21/09/2026 Security & SSRF Guards Engineered articleService.js and validation.js with comprehensive SSRF protection: DNS pre-lookup, private IP blocking (10.0.0.0/8, 127.0.0.1, 192.168.0.0/16, ::1), redirect caps, and 2MB payload limits. 3 hr Safe article fetching with Cheerio HTML extraction secured.
26/09/2026 Image Upload Security Implemented Multer memory storage and binary magic bytes validation in uploadValidation.js for JPEG, PNG, and WebP signatures. Prevented file extension spoofing and executable uploads. 2 hr Strict image upload validation up to 5MB implemented.
01/10/2026 AI Verification Engine Built 7-stage fact-checking pipeline in verificationService.js: claim extraction, entity recognition, live news cross-referencing, structured JSON verdicts (SUPPORTED to UNVERIFIED) with English reports. 3 hr Tri-modal AI verification engine with zero-cost fallback mode complete.
05/10/2026 Frontend Engineering Engineered TrueWire frontend matching dark newsroom UI (#0F1521, #E8A33D). Built Fraunces serif typography, live digital clock, smooth CSS marquee ticker, and 2-column Live Desk layout. 3 hr Responsive newsroom command center frontend implemented.
08/10/2026 Verifier & Search UI Implemented segmented tabs (TEXT, LINK, IMAGE) with client-side image drag-drop preview, one-click claim prefill from Live Wire, live search supporting Hindi Devanagari, and channel filter chips. 3 hr Interactive The Verifier form and Live Wire search integrated.
10/10/2026 Testing & Deployment Created automated test suite (run-tests.js) testing SSRF guards, viral Hindi claims, image signatures, rate limits, and health diagnostics. Verified 32/32 tests passing and production readiness. 3 hr 32/32 test cases passed; deployment ready on localhost:3000.
